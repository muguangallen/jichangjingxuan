## 核心结论

看懂节点测速需要关注三个层次：**1. 客户端与入口的延迟；2. 单线程极限下载速率（决定视频秒开）；3. 晚高峰时段的测速曲线平滑度（决定是否丢包）**。

## 关键指标对照

| 测速指标 | 理想数值区间 | 说明 |
| :--- | :--- | :--- |
| **TCP 延迟** | < 50ms (香港/日本) | 握手建连所需时间 |
| **单线程下载** | > 100 Mbps | 4K流媒体流畅播放的基础 |
| **丢包率** | < 1% | 低丢包才是持续流畅的关键 |
